# anken_formatter 基本設計メモ（現行実装準拠 / v0.1）

## 1. 概要

**anken_formatter** は、案件テキスト（例：求人票・案件紹介など）を解析し、
必要な情報を抽出して **コンソールに出力** し、さらに **TSV（タブ区切り文字列）をWindowsクリップボードにコピー** する Python ツールです。

本ツールの目的は、案件情報を Excel 転記・管理しやすい形に整えることです。
当面は単一ファイル入力＋コンソール出力のみ対応し、拡張性を考慮した構成とします。

---

## 2. 主な特徴

* `.sample/anken1.txt` のようなテキストファイルから案件情報を抽出
* 見出し（例：`【内容】`, `【スキル】`, `【金額】`）を正規表現で検出し、本文を解析
* 抽出結果を **タブ区切り形式** に整形して出力
* Windows環境では、出力文字列を **クリップボードに自動コピー**

---

## 3. 入出力仕様

### 入力

* **対象ファイル**：UTF-8テキスト
* **ファイル指定**：ソースコード内のパス指定（例：`.sample/anken1.txt`）
* **構造**：案件見出し（`【内容】`、`【スキル】`など）で区切られたブロック構成

### 出力

* **コンソール出力**

  * 整形済みデータ（確認用JSON風表示）
  * タブ区切り1行データ（Excel転記用）
* **クリップボード**

  * Windows環境の場合：`clip` コマンド経由でタブ区切り文字列をコピー
  * 非Windows環境ではスキップ（警告表示）

---

## 4. 抽出項目と出力順序（TSV列順）

| 項目名     | 抽出元          | 出力形式               |
| ------- | ------------ | ------------------ |
| 参画時期    | 【期間】         | YYYY/MM（例：2025/11） |
| 勤務形態    | 【場所】         | フルリモート／常駐(地名)      |
| 報酬額(税込) | 【金額】         | スキル見合い／60〜80万円 など  |
| スキル必須   | 【スキル】（尚可前まで） | 「・」区切り→ `/` 結合     |
| スキル尚可   | 【スキル】（尚可以降）  | 同上                 |
| 業務内容    | 【内容】         | 箇条書き→ `/` 結合       |
| 清算幅下限   | 【精算】         | 数値（例：140）          |
| 清算幅上限   | 【精算】         | 数値（例：180）          |
| 契約期間    | 【期間】         | YYYY/MM末 など        |

> 抽出できない項目は空文字として出力します。

## 5. 実装構成（v0.1 現行）

### ファイル構成

```
anken_formatter_main.py
.sample/
 └ anken1.txt
```

### 主な構成要素（1ファイル内）

| 区分           | 主な関数・クラス                                 | 役割                  |
| ------------ | ---------------------------------------- | ------------------- |
| **データモデル層**  | `AnkenRecord`                            | dataclass。抽出結果を保持   |
| **入出力層**     | `read_text`, `copy_to_windows_clipboard` | テキスト読込・クリップボード出力    |
| **解析層**      | `split_sections`, `extract_*` 系関数群       | 正規表現でセクション抽出と項目解析   |
| **整形層**      | `record_to_tsv`, `list_to_field`         | TSV整形、配列項目の結合       |
| **モード層**     | `parse_mode_jp_basic_v1`                 | フォーマット別パーサ（初期版）     |
| **エントリポイント** | `main()`                                 | メイン処理（読込→解析→出力→コピー） |

## 6. モード設計（フォーマット差異対応）

複数フォーマットに対応するため、**モードごとにパーサ関数を登録**します。

```python
PARSER_REGISTRY = {
    "jp_basic_v1": parse_mode_jp_basic_v1
}
```

将来、別形式（例：`jp_basic_v2`, `en_basic_v1`など）が増えても、
同じ `AnkenRecord` データモデルを共通利用します。

---

## 7. 抽出処理の主なロジック

| 項目             | 主な処理概要                                             |
| -------------- | -------------------------------------------------- |
| **セクション分割**    | 正規表現 `^【(.+?)】` により見出しを検出。本文を次見出しまで抽出。             |
| **参画時期**       | `YYYY年M月` / `YYYY/M` / `M月` を抽出し `YYYY/MM` 形式に正規化。 |
| **契約期間**       | 「〜」「～」「-」右側の年月を抽出。末があれば `/末` 付与。                   |
| **勤務形態**       | `フルリモート` を優先。`常駐(...)` もそのまま保持。                    |
| **報酬額**        | 記載をそのまま文字列として出力。                                   |
| **スキル（必須／尚可）** | 「（尚可）」の前後で分割。行頭の「・」で項目化。                           |
| **業務内容**       | `【内容】` セクションの箇条書きを配列化。                             |
| **清算幅**        | `(\d{2,3})[〜～\-](\d{2,3})` を抽出し、数値化。               |

---

## 8. エラー・例外対応

| 対象               | 処理方針                       |
| ---------------- | -------------------------- |
| ファイル読込失敗         | `FileNotFoundError` を表示し終了 |
| 該当見出しがない         | 空文字または None として処理          |
| 清算幅逆転（例：180〜140） | 自動で下限≦上限に補正                |
| 非Windows環境       | クリップボードコピーをスキップし警告表示       |

---

## 9. 使用手順（v0.1）

1. `.sample/anken1.txt` に案件テキストを保存
2. `anken_formatter_main.py` を実行

```bash
python anken_formatter_main.py
```

3. コンソール出力を確認

   * 整形済みデータ（JSON風）
   * タブ区切り1行（TSV）
4. Windows環境では自動的にクリップボードへコピーされるため、
   そのままExcelに貼り付け可能。
